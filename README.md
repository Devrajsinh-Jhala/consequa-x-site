# Consequa-X website

Public source for the Consequa-X landing page, documentation, and synthetic
package walkthrough. The Python framework is available on
[PyPI](https://pypi.org/project/consequa-x/1.1.0/).

[Deploy to Render](https://render.com/deploy?repo=https%3A%2F%2Fgithub.com%2FDevrajsinh-Jhala%2Fconsequa-x-site)

The Blueprint creates one static site with root directory `website`, build
command `true`, and publish directory `dist`. Automatic deployments are off.
GitHub Actions are disabled. No API key, server, database, or dependency build
is needed for this website.

The current public site is at
https://consequa-x.brawny-deer-5658.chatgpt.site.
Render is a deployment destination; no Render URL is claimed before a successful
deploy. The sitemap currently points to the existing public host.

The GIF contains screenshots of an actual Consequa-X 1.1.0 HTML report generated
from synthetic example data. It is not a live payment or model session. The
offline report ZIP preserves the original self-contained HTML without hosting
additions. The interactive inspector is a separate labelled illustration.

Only reviewed public website files are included. Private research records,
papers, model requests, credentials, and the research repository's history
are excluded. Website code uses the MIT license; local fonts retain their OFL
licenses under `website/dist/fonts/`.
